2 Host

The menu is the codon-usage files installed with this page, from GET /v1/hosts. It is not a catalogue of every organism. The name is a label on the job and has to look like genus_species:taxid/strain. The filled-in name is the rpsL demo host. The table is what the optimizer uses. The bundled table is examples/mg1655_ribosomal_usage.json, counted from E. coli K-12 MG1655 ribosomal proteins and labelled user-supplied.

CAI (codon adaptation index) compares your gene with this table. 1.0 means every counted codon is a top synonym of the table that was loaded. Stops and single-codon families are excluded. A codon whose weight is 0 makes the whole CAI 0. Kazusa (taxid 316407) is genome-wide frequencies converted to relative adaptiveness. Loading it replaces the table the search uses, so the result is a different number, not a second column on the ribosomal score. Upload accepts a codon_usage JSON, a Kazusa or CoCoPUTs-style CSV or text file, or a FASTA of coding sequences. The server counts or normalizes it and labels the result user-supplied unless you already marked the file. There is still no downloaded catalogue of species.

No codon table loaded yet.

Paste Kazusa text (triplet and a count in parentheses), a codon and count table, or FASTA coding sequences. Relative adaptiveness is each count divided by the maximum in its synonymous family. Unobserved families stay at 0. No pseudocount is added. The table is stored as user_supplied, not as a highly expressed Sharp and Li set, unless you say so. 3 Rules optional

Constraints are hard limits, separate from scores. Leave this on “No extra rules” for a first run. The rpsL example file, examples/rpsL_constraints.json, is named as an empty demonstration set: its list is empty, so it checks nothing.

Each button loads that preset into the JSON box and sends it. BioBrick RFC[10] forbids EcoRI, XbaI, SpeI, PstI and NotI. Golden Gate forbids BsaI and BsmBI. Synthesis forbids a 50 nt GC window outside 40–60%, a homopolymer longer than 6, and a repeated 12-mer. A rule this version does not search is reported as CF-FEAS-008 rather than treated as satisfied.

Common synthesis and cloning limits

A homopolymer is the same base repeated, such as AAAAAA. Many synthesis companies refuse long runs.

A GC window is a sliding stretch of the gene. The fractions are 0 to 1 (0.50 is 50% G and C). This is a hard band on every window. It is not the GC-fraction score in the next step, which is one number for the whole gene and, if you select it, is pushed downward.

Paste a constraint-set document, or load the example and edit it. A file this page does not understand is reported back with a CF-FEAS code rather than ignored.

Codon adaptation index. Higher means the codons look more like the highly expressed genes in the table you loaded. This is the usual first objective. The search maximizes it.

The share of the gene that is G or C, as one number. The search minimizes it, so selecting it pushes GC down. It is not a target and not a GC window. Use the GC-window rule above if you want a band.

How many constraint rules the sequence still breaks. The result table says whether this term was ranked on or only reported.

Minimize the mean absolute difference between each input codon’s relative adaptiveness in the source table and the chosen codon’s relative adaptiveness in the expression-host table. The method is Claassens et al., PLoS ONE 2017. The input DNA’s codons are the source choices. A protein paste is reverse-translated first, so those codons are not a natural gene.

Not loaded. Harmonization refuses to invent this table.

Minimize the squared difference between the gene’s synonymous codon fractions and the host table’s fractions. This is not CAI. CAI piles onto the top codon. The term couples every synonym of an amino acid, so only the population loop ranks it.

How folded the messenger RNA is near each codon. ViennaRNA reports an accessibility from its partition function. If it is missing, the job refuses this objective with CF-STRU-003 rather than inventing a score. UNKNOWN means not measured. It is not zero and it is not a bad score.

Nussinov is an opt-in maximum matching: pair score 1 for A–U, G–C and G–U, hairpin of at least 3 (Nussinov and Jacobson, PNAS 1980). The score is the mean paired fraction between 0 and 1. It is not a free energy in kcal/mol and not an unpaired probability. Temperature does not enter it. It is not used unless you select it.

6 Lab measurement optional

Record a number you measured. It is stored and can be downloaded as CSV. The server may fit a straight line of that number against GC fraction. That line does not change codon choices, and no sequence model is trained.

What this version does not do

A request this build cannot run answers CF-CLI-003. Nothing is silently skipped.

  • Dwell is not scored (CF-LAND-001). No paper states one 5′ A-site offset for GEO GSE53767, so this version does not invent one and does not report a zero deviation.
  • GET /v1/hosts is the codon-usage files installed here, not a list of every organism. A name you type still needs a table. Import a Kazusa file, a count table, or your own CDS set for another organism.
  • GET /v1/models is the verified context model, or an empty list when that file is not installed. A saved lab measurement is stored and exported. The GC-fraction line, when one can be fit, does not change codon choices. No sequence model is trained.
  • Feasibility reports a proof only when it can show a synonymous CDS the checker accepts, or an exact finding. Otherwise the report says the checks are necessary conditions and the set is unknown.
  • Nussinov is an approximate matching you must opt into. It is not used when ViennaRNA is missing, and it is not a free-energy score.
  • On the assembly rules, rpsL stays at CAI 0.9866866273575934. CAG at codon 74 is blocked by PstI, and GAC at codon 88 by a 12-mer whose cheapest feasible repair costs more CAI than that codon returns. The higher number is an infeasible sequence.
