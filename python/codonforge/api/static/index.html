CodonForge keeps the protein the same and changes which codons spell it, so the gene suits the host you name. Five steps. The later ones already have a working default.

1 Coding sequence

Paste the coding sequence only (the part that is translated), or a FASTA file’s sequence. It should start with a start codon, use A, C, G and T, and its length should divide by 3. A protein sequence (M, L, K…) is not accepted here.

2 Host

The name is a label on the job. The codon table in the next step is what the optimizer actually uses. The bundled table is from E. coli K-12 MG1655 ribosomal proteins. If you pick another host, load that host’s table.

3 Codon-usage table

CAI (codon adaptation index) compares your gene with this table. 1.0 means every counted codon is a top synonym of the table that was loaded. Stops and single-codon families are excluded. A codon whose weight is 0 makes the whole CAI 0. The first button loads examples/mg1655_ribosomal_usage.json, counted from ribosomal-protein genes and labelled user-supplied. The page loads it when it opens. Kazusa (taxid 316407) is genome-wide frequencies converted to relative adaptiveness. Loading it replaces the table the search uses, so the result is a different number, not a second column on the ribosomal score. A finished design also reports the Kazusa number beside the table it optimized.

No codon table loaded yet.

4 Constraints optional

Constraints are hard limits, separate from scores. Leave this on “No extra rules” for a first run. The rpsL example file, examples/rpsL_constraints.json, is named as an empty demonstration set: its list is empty, so it checks nothing.

Each button loads that preset into the JSON box and sends it. BioBrick RFC[10] forbids EcoRI, XbaI, SpeI, PstI and NotI. Golden Gate forbids BsaI and BsmBI. Synthesis forbids a 50 nt GC window outside 40–60%, a homopolymer longer than 6, and a repeated 12-mer. A rule this version does not search is reported as CF-FEAS-008 rather than treated as satisfied.

Common synthesis and cloning limits

A homopolymer is the same base repeated, such as AAAAAA. Many synthesis companies refuse long runs.

A GC window is a sliding stretch of the gene. The fractions are 0 to 1 (0.50 is 50% G and C). This is a hard band on every window. It is not the GC-fraction score in the next step, which is one number for the whole gene and, if you select it, is pushed downward.

Paste a constraint-set document, or load the example and edit it. A file this page does not understand is reported back with a CF-FEAS code rather than ignored.

5 What to optimize

Objectives
Scores. CAI is enough for a first design.

Codon adaptation index. Higher means the codons look more like the highly expressed genes in the table you loaded. This is the usual first objective. The search maximizes it.

The share of the gene that is G or C, as one number. The search minimizes it, so selecting it pushes GC down. It is not a target and not a GC window. Use the GC-window rule above if you want a band.

How many constraint rules the sequence still breaks. The result table says whether this term was ranked on or only reported.

How folded the messenger RNA is near each codon. The computer running this server needs ViennaRNA installed; CodonForge does not include it. If it is missing, the job can still finish and this score is shown as UNKNOWN. UNKNOWN means not measured. It is not zero and it is not a bad score.

Advanced options

The budget chooses which search stages run. Fast runs two stages (a first pass, then a polish) and is the right first choice. Standard adds a population of alternative designs, evolved for the number of generations below. Exact also asks for a final ranking stage this version does not run; the job says so with CF-ORCH-006 and still returns the earlier stages. Tiers are those stages. The progress panel shows one row per tier, not a single percentage.

What this version does not do

These requests answer CF-CLI-003. Nothing is silently skipped. Use the form above instead of those routes.

  • There is no host catalog. Type the host and load a codon table. GET /v1/hosts is not a list of organisms.
  • There is no model catalog, and this page has no form for a lab measurement. POST /v1/observations stores a validated measurement. GET /v1/recalibrations answers CF-CLI-003 and does not refit a model.
  • A protein sequence is not reverse-translated, and a multi-gene construct is not expanded. Paste one DNA coding sequence.
  • The separate feasibility route is not wired. After a job, read constraint_report.feasible on the design. It is true or false.
  • Importing another optimizer’s output is not wired.

PrimerForge picks a forward and a reverse primer around a region you select. NCBI BLAST is not part of this tool. Specificity against a genome is not checked.

Sequence

Paste the DNA you will amplify. A FASTA header (a line starting with > or ;) is dropped before numbering, the same way the API drops it, so the header does not shift the region. Lowercase is read as uppercase. A letter that is not A, C, G or T is named with its position and the search does not run. Then drag across the letters, or type a start and end.
