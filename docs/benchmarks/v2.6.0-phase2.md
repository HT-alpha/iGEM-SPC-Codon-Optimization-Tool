# DNA Design Suite v2.6.0 — structure and burden fronts

Measured on this tree after `make check` (315 pytest). Host
`escherichia_coli:511145/BL21`. Codon weights
`examples/mg1655_ribosomal_usage.json`. Constraints
`benchmarks/validation/constraints_assembly.json` (50 nt GC windows 0.40–0.60,
seven restriction sites, homopolymer runs longer than 6, `AGGAGG` on both
strands, repeated 12-mers). Translation table 11. Seed 7. Budget `standard`,
4 generations, stagnation window 21, population 12. ViennaRNA 2.7.2.

Independent ribosomal CAI is `benchmarks/validation/cai_independent.py` on
that same table. It excludes stops and the single-codon families Met and Trp.
The search's `usage.cai` is the value in the objective vector.

`structure.local_accessibility` is the accessibility penalty: mean negative
log unpaired probability, window 6 nt, span 40 nt, 37°C, on the CDS. Lower is
better. The input row is a separate fold of the input CDS with that function.
The input's own objective vector leaves the axis unknown, because tiers 1 and
2 do not fold (`CF-SRCH-010`).

`burden.growth_cost` on the input is the in-core score from the
three-objective run. Lower is better. It is a dimensionless mismatch, not a
growth rate. A flat synonymous mix on this prior is 0.5.

Every designed CDS below is feasible and translates to the input protein.
Every input CDS is infeasible under the assembly rules. Wall times are this
machine, one process, and include the search.

are minimized. The rule is `feasible_then_score_then_digest` when CAI is the
only axis, and `knee_of_complete_front` otherwise. On the multi-objective
runs every requested term is in `informed_by` and `not_informed_by` is empty.

## Warnings on these runs

CAI-only: `CF-LAND-013` (structure computed as a diagnostic, not ranked),
`CF-SRCH-001` (a context operator is absent and the mix was renormalized),
`CF-SRCH-017` (tier 1 could not carry a non-local rule; later stages started
from the repaired seed).

Structure requested: `CF-SRCH-010` instead of `CF-LAND-013`. Some runs also
emit `CF-SRCH-016` (the structure batch did not reach every individual) and
`CF-ORCH-007` (the scalar best is not the last stage's scalar). The
recommendation on those runs is the knee, not that scalar.
